把个人网站做成一个会持续生长的工程

本周围绕个人网站的视觉系统和公开动态能力，完成了一轮连续迭代。

统计周期：2026-09-07 至 2026-09-13（Asia/Shanghai）

从三条轨道到一个太阳系

本周最集中的工作，是把首页主视觉从静态轨道图形推进成一个可持续运行的太阳系场景。现在画面由中心太阳、九条不同半径的椭圆轨道和九颗行星组成。每颗行星使用独立的 SVG animateMotion 路径和周期，因此它们以不同速度运行。

中心太阳使用径向渐变、阴影和呼吸动画，九条轨道用不同透明度和色相区分层次。背景保留网格、Aurora 光晕以及 Canvas 星尘层，让轨道场景拥有更明显的空间感。

提交曲线的失败状态修复

网站的 GitHub 提交曲线允许部分仓库请求失败，仍然绘制能够取得的数据；如果所有请求都失败，则保留坐标网格并显示明确提示。

Kotlin 动态区块的取舍

页面新增了 Kotlin 生态动态区块，优先读取 JetBrains Kotlin Blog 的 RSS，同时准备 Kotlin 官方网站的备用内容。Kotlin 图标已按你的要求移除。

可验证的结果

  • 首页主视觉升级为九行星太阳系动画。
  • 提交曲线不再因单个仓库请求失败而整体清空。
  • Kotlin 最新动态区块支持官方 RSS 与备用内容。
